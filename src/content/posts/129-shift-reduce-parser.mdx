## Introduction

A **shift reduce parser** is a bottom-up parser that builds the parse tree from the leaves (input symbols) up to the start symbol. It uses a stack to hold grammar symbols and performs two basic actions:

- **SHIFT:** move the next input symbol onto the stack.
- **REDUCE:** replace a handle (right-hand side of a production) on top of the stack by its left-hand side non-terminal.

The grammar used here is:

- **E → E + E**
- **E → E - E**
- **E → E \* E**
- **E → ( E )**
- **E → id**

If the whole input can be shifted and reduced to the start symbol `E`, the string is accepted; otherwise it is rejected.

## Algorithm

**Step 1:** Start the program.

**Step 2:** Read the input string into `input`.

**Step 3:** Initialize an empty stack with `top = -1` and input index `i = 0`.

**Step 4:** Display the header `stack input action`.

**Step 5:** While input symbols remain (`i < n`):
   - **SHIFT:** push `input[i]` onto the stack and advance `i`.
   - If the pushed symbol is `i` and the next input symbol is `d`, push that `d` as well (so `id` is shifted together) and display `SHIFT->id`. Otherwise display `SHIFT->symbol`.
   - **REDUCE:** after every shift, check the top of the stack:
     - If the top is `id`, pop both symbols and push `E`.
     - Else if the top is `E op E` where `op` is `+`, `-` or `*`, pop three symbols and push `E`.
     - Else if the top is `( E )`, pop three symbols and push `E`.
   - Display `REDUCE TO E` whenever a reduction is performed.

**Step 6:** After the input is exhausted, if the stack contains only `E` (`top == 0` and `stack[0] == 'E'`), display `Accept`. Otherwise display `Reject`.

**Step 7:** Stop the program.

## Program

```c
#include <stdio.h>
#include <string.h>

char stack[50], input[50];
int top = -1;

void reduce()
{
    if (top >= 1 && stack[top-1] == 'i' && stack[top] == 'd')
    {
        stack[top-1] = 'E';
        top--;
        stack[top+1] = '\0';
        printf("$%s\t%s$\tREDUCE TO E\n", stack, input);
    }

    if (top >= 2 && stack[top-2] == 'E' &&
        (stack[top-1] == '+' || stack[top-1] == '-' || stack[top-1] == '*') &&
        stack[top] == 'E')
    {
        stack[top-2] = 'E';
        top -= 2;
        printf("$%s\t%s$\tREDUCE TO E\n", stack, input);
    }

    if (top >= 2 && stack[top-2] == '(' &&
        stack[top-1] == 'E' && stack[top] == ')')
    {
        stack[top-2] = 'E';
        top -= 2;
        printf("$%s\t%s$\tREDUCE TO E\n", stack, input);
    }
}

int main()
{
    int i = 0, n;

    printf("Grammar is E->E+E\n");
    printf("E->E-E\n");
    printf("E->E*E\n");
    printf("E->(E)\n");
    printf("E->id\n");

    printf("Enter input string:\n");
    scanf("%s", input);

    n = strlen(input);

    printf("stack\tinput\taction\n");

    while (i < n)
    {
        stack[++top] = input[i++];

        if (stack[top] == 'i' && i < n && input[i] == 'd')
        {
            stack[++top] = input[i++];
            stack[top+1] = '\0';
            printf("$%s\t%s$\tSHIFT->id\n", stack, input+i);
        }
        else
        {
            stack[top+1] = '\0';
            printf("$%s\t%s$\tSHIFT->symbol\n", stack, input+i);
        }

        reduce();
    }

    if (top == 0 && stack[0] == 'E')
        printf("$E\t$\tAccept\n");
    else
        printf("Reject\n");

    return 0;
}
```

## How to Run

**Step 1:** Compile `program.c` using `gcc`.

**Step 2:** Run the executable and enter an input string built from `id`, `+`, `-`, `*`, `(` and `)` without spaces.

```bash
gcc program.c
./a.out
```

### Test Cases

The parser gives the following verdicts:

- `id+id` → **Accept**
- `id*id` → **Accept**
- `(id)` → **Accept**
- `(id+id)*id` → **Accept**
- `id+` → **Reject** (dangling operator, stack is not a single `E`)
- `(id+id` → **Reject** (missing closing parenthesis)
- `id++id` → **Reject** (consecutive operators, no valid handle to reduce)
