## Introduction

**FIRST(X)** is the set of terminals that can appear as the first symbol in a string derived from `X`. **FOLLOW(X)** is the set of terminals that can appear immediately to the right of `X` in some sentential form. These sets are the foundation for constructing LL(1) (predictive) parse tables.

The rules used by the program are:

- **FIRST of a terminal:** `FIRST(t) = { t }`.
- **FIRST of a non-terminal:** `FIRST(X)` contains the first terminals of every production `X → α`. If `α` can derive epsilon, then `FIRST(X)` also contains `#` (epsilon).
- **FOLLOW of the start symbol** always contains `$` (end of input marker).
- **If `A → αBβ`:** add `FIRST(β) - {#}` to `FOLLOW(B)`. If `β` can derive epsilon, add `FOLLOW(A)` to `FOLLOW(B)`.
- **If `A → αB`:** add `FOLLOW(A)` to `FOLLOW(B)`.

## Algorithm

**Step 1:** Start the program.

**Step 2:** Read the number of productions `n`.

**Step 3:** Read each production as a string of the form `LHS=RHS` (for example `S=AB`), using `#` to represent epsilon.

**Step 4:** Collect all non-terminals from the left-hand sides.

**Step 5:** For each non-terminal, compute `FIRST`:
   - If the symbol is a terminal, add it directly.
   - For each production `A → α`, compute FIRST of the symbols in `α` one by one, stopping when a symbol whose FIRST does not contain `#` is reached.
   - If every symbol in `α` can derive epsilon, add `#` to `FIRST(A)`.

**Step 6:** For each non-terminal, compute `FOLLOW`:
   - Add `$` to FOLLOW of the start symbol.
   - For every occurrence of a non-terminal `B` in a production `A → αBβ`, add `FIRST(β) - {#}` to `FOLLOW(B)`. If `β` can derive epsilon, add `FOLLOW(A)` to `FOLLOW(B)`.

**Step 7:** Display the FIRST and FOLLOW sets of every non-terminal.

**Step 8:** Stop the program.

## Program

```c
#include <stdio.h>
#include <string.h>
#include <ctype.h>

#define MAX 20
char production[MAX][MAX];
char first[MAX][MAX], follow[MAX][MAX];
int n;

int isPresent(char str[], char ch) {
    int i;
    for (i = 0; str[i] != '\0'; i++) {
        if (str[i] == ch) return 1;
    }
    return 0;
}

void addToSet(char str[], char ch) {
    if (!isPresent(str, ch)) {
        int len = strlen(str);
        str[len] = ch;
        str[len + 1] = '\0';
    }
}

void findFirst(char result[], char symbol) {
    int i, j;
    char temp[MAX] = "";
    if (!isupper(symbol)) {
        addToSet(result, symbol);
        return;
    }
    for (i = 0; i < n; i++) {
        if (production[i][0] == symbol) {
            if (production[i][2] == '#') {
                addToSet(result, '#');
            } else {
                int k = 2;
                int epsilon = 1;

                while (production[i][k] != '\0' && epsilon) {
                    epsilon = 0;

                    findFirst(temp, production[i][k]);

                    for (j = 0; temp[j] != '\0'; j++) {
                        if (temp[j] != '#') addToSet(result, temp[j]);
                    }

                    if (isPresent(temp, '#')) epsilon = 1;

                    k++;
                }

                if (epsilon) addToSet(result, '#');
            }
        }
    }
}
void findFollow(char symbol) {
    int i, j, k;
    char temp[MAX] = "";
    if (symbol == production[0][0])
        addToSet(follow[symbol - 'A'], '$');

    for (i = 0; i < n; i++) {
        for (j = 2; production[i][j] != '\0'; j++) {
            if (production[i][j] == symbol) {
                int next = j + 1;
                int epsilon = 1;

                while (production[i][next] != '\0' && epsilon) {
                    epsilon = 0;
                    strcpy(temp, "");

                    findFirst(temp, production[i][next]);

                    for (k = 0; temp[k] != '\0'; k++) {
                        if (temp[k] != '#')
                            addToSet(follow[symbol - 'A'], temp[k]);
                    }

                    if (isPresent(temp, '#'))
                        epsilon = 1;

                    next++;
                }

                /* If beta can produce epsilon */
                if (production[i][next] == '\0' && symbol != production[i][0]) {
                    findFollow(production[i][0]);

                    for (k = 0; follow[production[i][0] - 'A'][k] != '\0'; k++) {
                        addToSet(follow[symbol - 'A'],
                                 follow[production[i][0] - 'A'][k]);
                    }
                }
            }
        }
    }
}

int main()
{
    int i;
    char nonTerminals[MAX];
    int ntCount = 0;

    printf("Enter number of productions: ");
    scanf("%d", &n);

    printf("Enter productions (use # for epsilon):\n");

    for (i = 0; i < n; i++) {
        scanf("%s", production[i]);
    }

    /* Find FIRST */
    for (i = 0; i < n; i++) {
        char lhs = production[i][0];

        if (!isPresent(nonTerminals, lhs)) {
            nonTerminals[ntCount++] = lhs;
            nonTerminals[ntCount] = '\0';
        }

        strcpy(first[lhs - 'A'], "");
        findFirst(first[lhs - 'A'], lhs);
    }

    /* Find FOLLOW */
    for (i = 0; i < ntCount; i++) {
        findFollow(nonTerminals[i]);
    }

    printf("\nFIRST sets:\n");

    for (i = 0; i < ntCount; i++) {
        char nt = nonTerminals[i];

        printf("FIRST(%c) = { ", nt);

        for (int j = 0; first[nt - 'A'][j] != '\0'; j++)
            printf("%c ", first[nt - 'A'][j]);

        printf("}\n");
    }

    printf("\nFOLLOW sets:\n");

    for (i = 0; i < ntCount; i++) {
        char nt = nonTerminals[i];

        printf("FOLLOW(%c) = { ", nt);

        for (int j = 0; follow[nt - 'A'][j] != '\0'; j++)
            printf("%c ", follow[nt - 'A'][j]);

        printf("}\n");
    }

    return 0;
}
```

## How to Run

**Step 1:** Compile `program.c` using `gcc`.

**Step 2:** Run the executable and supply the grammar as input.

```bash
gcc program.c
./a.out
```

**Input format:** First enter the number of productions, then each production as a single string with the left-hand side, an `=` sign, and the right-hand side immediately after it (for example `S=AB`). Use `#` for epsilon. Non-terminals are single uppercase letters; terminals are lowercase letters or symbols.
